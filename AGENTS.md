# Instructions for AI coding agents

This is a candidate's workspace for the Sysnova Junior Data Programmer assessment.
Read `AI_AGENT_GUIDELINE.md` (section 5) and `TASK.md` first, and follow them:

- Follow the business rules in `TASK.md` exactly. Ask the human about unclear points.
- Never modify `data/raw/`. Never make up results, counts or test output.
- Keep changes small and explain them so the human can understand them.
- Never write `AI_USAGE.md` for the human; it must reflect real usage.
- Stay in the project folder. Never commit secrets or database passwords.
