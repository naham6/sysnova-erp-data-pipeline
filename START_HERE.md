# START HERE

Welcome, and thank you for doing this assessment for Sysnova.

## Read in this order
1. **`TASK.md`**: what to build, the business rules, and what to submit
2. **`DATA_DICTIONARY.md`**: what is in each data file
3. **`AI_AGENT_GUIDELINE.md`**: only if you decide to use AI tools (using AI is optional)

## What is in this package
```
TASK.md                  the assessment brief
DATA_DICTIONARY.md       the data files and how they relate
AI_AGENT_GUIDELINE.md    rules, only if you choose to use AI tools
AI_USAGE_TEMPLATE.md     only if you used AI: copy to AI_USAGE.md and fill in
AGENTS.md                short note picked up automatically by AI coding agents (ignore it if you do not use AI)
sql/slow_query.sql       only for the optional q4 task
data/raw/                the input CSV files (read-only: do not edit)
```

## How to start
1. Create a **new public GitHub repository** and copy these files into it. Commit this starting point first.
2. Install PostgreSQL if you can (MySQL, SQL Server or Oracle are also fine).
3. Work through the required tasks in `TASK.md`. Commit small and often: your Git history is part of what we look at.
4. Write your own `README.md` (see Task 5 in `TASK.md`).

## Time
- Plan for **about 5-6 hours**.
- **Do not worry about completing the whole task.** Submit whatever you have done, and write in your README what is
  missing and what you would do next. A solid, well-explained partial submission is better than a rushed complete one.
- **Freshers are welcome.** Tell us honestly what you know and what you learned.

## Suggested layout of your repo
```
README.md
AI_USAGE.md     (only if you used AI)
sql/        01_create_raw.sql, load script, cleaning scripts, q1.sql ... q3.sql
docs/       data_issues.md
results/    q1.csv ... q3.csv, summary.json
data/raw/   (provided)
```
Optional extras (q4, a report, an ER diagram) can go in `sql/`, `docs/` and `report/`.

## When you are done
Email the public repository link to **jobs@sysnova.com**, with the subject *DA Assessment - your name*.
If something in the brief is unclear, email the same address. We reply to everyone with the same answer.

Good luck!
